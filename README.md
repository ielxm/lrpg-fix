# lrpg_fix

## Dependencies
This script depends on AutoHotkey v1.1.

## How to use
Replace ``NAME`` on line 3 of ``lrpg_fix.ahk`` with the exact name of the application you want to force to work in borderless fullscreen, then run the application first, and only after that — run the script.

If your monitor's resolution is not 1920x1080, you need to change the values of width and height on line 13 of ``lrpg_fix.ahk`` — type your width and height and add 14 pixels to both.
